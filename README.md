# Témpano

Pista de hielo municipal B2C: sesiones de 60 min (Norte pública con aforo compartido / Sur privada), alquiler de patines por talla EU, hold de 15 min, ticket QR y check-in de staff.

**Demo:** `demo@tempano.dev` / `demo1234`  
**Staff:** `staff@tempano.dev` / `demo1234`  
**API:** puerto 3072 · JWT namespaced `tempano.accessToken`

## Stack

Angular 22 (signals, zoneless) + NestJS 11 + TypeORM + SQLite (Neon-ready).
